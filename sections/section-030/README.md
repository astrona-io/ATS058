# eBPF-based Platforms versus IPtables-based Platforms

This section covers eBPF-based Platforms versus IPtables-based Platforms. It develops comparing eBPF And iptables Networking Models through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Describe rule traversal and map-based processing conceptually.
- Distinguish kube-proxy replacement from every host firewall mechanism.
- Explain connection state and hook placement tradeoffs.
- Evaluate coexistence and measurements rather than universal winner claims.
