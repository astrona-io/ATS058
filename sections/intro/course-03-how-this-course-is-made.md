# How This Course Is Made

Authors map each section to an official CCA objective. They check each mechanism and each command against the primary project documentation before they write it. They also check that every example names the component that does the work and that it states its limits.

Static checks verify the page order, the length and structure of each page, the front matter, the YAML files and the shell scripts. The labs and playgrounds validate with the `astrona` tool. The material has not been run on a live cluster yet, so the technical pages stay marked as draft until a review confirms the runtime behavior.

The [contributors](https://github.com/astrona-io/ATS058/graphs/contributors) maintain the material. To [report a mistake](https://github.com/astrona-io/ATS058/issues), name the page and the statement that you dispute. The [license](https://github.com/astrona-io/ATS058/blob/main/LICENSE) governs reuse.

The exam objectives belong to their owners. The teaching text and the knowledge checks are original practice material.
